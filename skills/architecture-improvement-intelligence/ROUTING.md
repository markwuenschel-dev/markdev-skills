# ICA V2 Downstream Routing

ICA stops before implementation.

## Expanded Grill

Use when one bounded architecture candidate contains consequential unresolved design decisions that benefit from deep interrogation. Evidence and the architecture candidate constrain the grill; Expanded Grill retains its own mandatory decision-coverage sweep.

## Decision Terrain Mapper

Use when the candidate unfolds into several independent/coupled decision surfaces and the durable relationship/frontier between those decisions matters. ICA does not create a persistent decision graph itself.

## Prototype

Use when a material architecture choice depends on empirical runtime/library/performance behavior that static evidence cannot settle efficiently.

## Ready for integrity/execution planning

Use only when the structural direction is sufficiently determined, material owner-intent decisions are settled, verification obligations are explicit, and no further architecture interview is required.

## Documentation proposals

ICA is read-only. Proposed changes to `CONTEXT.md`, ADRs, architecture docs, or terminology are returned as proposals to the authorized caller; ICA does not edit them during analysis.
