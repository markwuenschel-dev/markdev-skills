# Sources

prompt-forge synthesizes and condenses ideas from the following upstream projects. It contains no verbatim copies of their files; concepts and structures were adapted and rewritten. Licenses permit this with attribution.

| Upstream | What was absorbed | License |
|----------|-------------------|---------|
| [nidhinjs/prompt-master](https://github.com/nidhinjs/prompt-master) | Intent-contract dimensions, delivery format, diagnostic checklist seeds, fabrication-risk technique guard, credential/injection safety rules, non-LLM surface conventions | MIT |
| [muratcankoylan/Agent-Skills-for-Context-Engineering](https://github.com/muratcankoylan/Agent-Skills-for-Context-Engineering) (`long-horizon-prompting`) | Pseudo-formal brief anatomy, non-counting outcomes, persistence×verification pairing, orchestration/diversity heuristics, pre-launch rubric, brief template, long-horizon gotchas | MIT |
| [getsentry/skills](https://github.com/getsentry/skills) (`prompt-optimizer`) | Capture contract, layer ownership, rules-vs-descriptive separation, eval-driven optimization loop (baseline → cluster → textual gradients → candidate beam → holdout), model-family notes, return package, stop conditions | Apache-2.0 |
| [CR-730/agent-system-prompt-architect-skill](https://github.com/CR-730/agent-system-prompt-architect-skill) | Nine-layer system-prompt architecture, prompt-vs-runtime separation, role-definition standard, capability-vs-runtime-spec tool contracts, reasoning control modes, safety/compliance standard, same-turn drafting contract | MIT |
| [hermes-labs-ai/lintlang](https://github.com/hermes-labs-ai/lintlang) | Static-heuristic linting philosophy and defect classes (tool-description ambiguity, missing constraint scaffolding, schema–intent mismatch, context boundary erosion, template contract violation, role confusion) that shaped `scripts/lint_prompt.py` and the failure catalog | Apache-2.0 |
| [sickn33/agentic-awesome-skills](https://github.com/sickn33/agentic-awesome-skills) (`prompt-engineer`) | Silent-craft ("magic mode") delivery discipline; clarify-sparingly triggers | repo license |
| [promptslab/Awesome-Prompt-Engineering](https://github.com/promptslab/Awesome-Prompt-Engineering) | Directory context for the programmatic-optimization escalation note (DSPy/MIPRO, TextGrad, OPRO lineages) | CC0/aggregation |
