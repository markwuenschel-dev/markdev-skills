# Migration from v1.3 to v2.0

## Package identity

The skill remains `expanded-grill-with-docs`, so this package can overwrite the prior installation without changing invocation names.

## Retained

Repository inspection, selected-direction boundaries, proportional specialist lanes, parent-owned synthesis, domain modeling, design comparison, optional prototypes, evolving documents, walking skeletons, rollout and recovery, consistency review, human approval, and the no-implementation boundary remain.

## Rebuilt interview core

Version 2.0 replaces the flat uncertainty-ledger-first loop with a decision dependency graph. It computes a research frontier and a human-decision frontier, prevents dependent questions from appearing in the same round, permits nonblocking parallel fact research, and recomputes the graph after every answer.

Every consequential user-facing question now includes a recommended answer, rationale, tradeoff, confidence, and what the decision unlocks. The parent owns the interview; child lanes can propose questions and recommendations but cannot run competing user interviews.

## Stronger closure

An explicit shared-understanding summary and human confirmation are now required before approval or delivery handoff. Deferral counts as settled only with an owner, consequence, and revisit trigger.

## Compatibility

`assets/uncertainty-ledger.yaml` remains as a projection for older consumers. New integrations should use `assets/decision-graph.yaml`. Existing document destinations remain valid.
