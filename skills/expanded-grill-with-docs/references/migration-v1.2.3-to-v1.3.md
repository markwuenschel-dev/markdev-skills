# Migration from v1.2.3 to v1.3

## Retained in the default skill

Repository inspection, uncertainty mapping, eight specialist perspectives, decision grilling, domain modeling, design comparison, proposal and specifications, requirements quality, walking skeleton, rollout and rollback, consistency review, human approval, and delivery handoff remain part of the shaping lifecycle.

## Recentered

Specialist lanes now return interview packets. The parent deduplicates and prioritizes questions, runs adaptive rounds, challenges the emerging model, updates lightweight documents continuously, and stops when remaining uncertainty is safely deferrable.

## Removed from the default package

Per-artifact validators, aggregate bundle validation, approval stamping, artifact hashes, combined digests, exact Markdown mirrors, synchronization receipts, authorization-grade path checks, and the large validator-fixture suite no longer gate ordinary shaping.

## Optional strict handoff

A mature design package may be passed to a separate `design-contract-hardening` capability for schemas, referential integrity, hashes, tamper detection, synchronization evidence, and machine authorization. The main skill does not require or emulate that capability.
