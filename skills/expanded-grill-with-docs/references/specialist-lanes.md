# Specialist Lanes

Read when multiple independent perspectives can resolve consequential uncertainties.

Select only relevant lanes:

1. Product and user outcome
2. Domain and terminology
3. Repository and current system
4. Technical and architecture
5. Data, API, schema, and migration
6. UX and operational workflow
7. Risk, security, and failure modes
8. Verification, rollout, and observability

Each lane receives named uncertainty IDs, bounded surfaces, and the `assets/lane-result.yaml` return contract. A lane gathers evidence and proposes questions; it does not decide, synthesize final documents, approve, or expand scope.

Launch lanes in parallel only when their evidence surfaces are independent. Run targeted follow-up lanes after answers change the decision model. Stop a lane when its uncertainty is resolved, disproved, or safely deferred.
