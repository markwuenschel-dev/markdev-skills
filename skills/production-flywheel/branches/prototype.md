# Production Flywheel — Prototype Branch Procedure

Use when prose is not enough to decide a design or implementation direction.

## Steps

1. Run `/prototype`.
2. Choose the prototype artifact by question type:
   - `LOGIC.md` for business logic, state transitions, or data shape.
   - `UI.md` for page layout, interaction design, or visual structure.

## Gate

- **Explicit Question**: The single explicit question to be answered is documented at the start.
- **Answer Captured**: The output and findings answering the question are documented in the prototype artifact.
- **Prototype Lifecycle**: The prototype is either deleted or explicitly marked for absorption into the final codebase.
